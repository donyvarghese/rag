# RAG Pipeline Tutorial

This project explores the fundamentals of Retrieval-Augmented Generation (RAG), following a hands-on tutorial.

### Concepts Covered
- Document ingestion and processing
- Text embeddings using Sentence Transformers
- Vector storage and retrieval with ChromaDB
- Semantic search with similarity and distance scores
- Modular Python coding

### Tech Stack
Python, NumPy, Sentence Transformers, ChromaDB, scikit-learn, and Jupyter Notebook.

### Purpose
Learning how to build a basic RAG retrieval pipeline and understanding how its components work together.

**Note:** This project is based on a tutorial and is intended for learning purposes.**
